# IMI Social Visuals Skill

Installable Codex skill for consistent Inovasi Maritim social posts and photo treatments in 1080x1350, 1080x1920, and 1080x1080.

The repository is private. Give each team member repository access before installation.

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo andrewbayu/imi-social-visuals-skill \
  --path skills/imi-social-visuals
```

See the [skill README](skills/imi-social-visuals/README.md) for usage, dependencies, and an example export. The [skill instructions](skills/imi-social-visuals/SKILL.md) contain the approved visual rules.
